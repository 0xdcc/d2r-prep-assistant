在开始之前，确认一遍。

检查真实依赖、输入版本、目录安全和可用空间。IPA 的无 Metal 路线不强制要求 Xcode；首次手机启动会编译着色器。

准备隔离环境

自动准备应用专用 Python 3.12、固定版本与哈希的五个 wheel、.NET 10；Windows 缺编译器时下载 LLVM-MinGW。用固定 CMake/Ninja 编译 SPIRV-Cross（最多两线程）。Mac 缺 Apple 命令行工具时需自行通过官方安装提示安装。不改全局环境。

可检查的过程，才值得开始。

固定源码与干净壳 → 隔离复制 → 真实上游打包器（首次 .NET 构建可能联网恢复 NuGet 依赖）→ 检查 pack_info、壳清单、可执行文件与 CRC → SHA-256 → 发布唯一 IPA。
